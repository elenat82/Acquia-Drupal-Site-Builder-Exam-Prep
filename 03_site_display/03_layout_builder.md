Il modulo Layout Builder è uno strumento di progettazione drag and drop che consente agli editor di creare layout per la visualizzazione dei contenuti. 

I layout predefiniti sono layout di pagina che verranno utilizzati finché non verranno specificati layout personalizzati, ad esempio, un layout predefinito per gli articoli si applica a tutti gli articoli del sito, ma non ai post del blog. E' possibile anche l'override per un singolo nodo.

Per creare un layout personalizzato sirimuovono innanzitutto le impostazioni predefinite in modo che la costruzione possa iniziare con un layout vuoto. Il primo passo è aggiungere una Sezione (le Sezioni sono i blocchi costitutivi di livello superiore dei layout di pagina).
Layout Builder include quattro layout di sezione: da layout a una colonna a layout a quattro colonne.
Alcuni layout di sezione presentano opzioni di configurazione aggiuntive che devono essere selezionate prima di essere aggiunte a una sezione. Ad esempio, per il layout a due colonne, è necessario scegliere la larghezza delle colonne.
